# Maglev reel — Google Flow prompts v2 (detailed)
How to use (better results than text-only):
1. In Flow, first make the START FRAME image with the "IMAGE" prompt (Nano Banana / Imagen). Generate 4, pick the one where the train looks right.
2. Then use "Frames to Video" with that image as the first frame and paste the "VIDEO" prompt.
3. One clip = one action. If a clip goes wrong, regenerate only that clip; don't add more actions to the prompt.
4. Paste the COMMON NEGATIVE at the end of every video prompt.

COMMON NEGATIVE (paste every time):
no text, no letters, no numbers, no logos, no company branding, no watermark, no subtitles, no people, no faces, no rails, no railway sleepers, no overhead electric wires, no pantograph, no sparks, no fire, no smoke from the train, train must not bend or change shape, train must not change direction, no extra train cars appearing, no morphing, no camera shake, no sudden cuts.

TRAIN DESCRIPTION (keep identical in every prompt for continuity):
"a modern Japanese-style superconducting maglev train: glossy pearl-white body, very long pointed aerodynamic nose (like a duck-bill, about one third of the first car), a single thin dark-blue stripe along the side, small dark tinted windows, smooth sides with no doors visible, no pantograph on the roof"

GUIDEWAY DESCRIPTION (keep identical):
"an elevated grey concrete U-shaped guideway: a flat concrete floor with two low concrete side walls about one metre high on both sides of the train, supported by concrete pillars; there are NO steel rails and NO sleepers"
